# Verified component inspiration and documentation
21st.dev components are individual source components, not one magic install-all plugin. Source may require a free account. Copy the exact component via its supplied workflow when accessible; never invent registry commands or claim source access. If inaccessible, implement the documented interaction yourself from the reference and label that honestly. Convert TypeScript examples to .jsx, remove Next.js-only imports, use img instead of next/image and Vite import.meta.env.BASE_URL where relevant. Review each component's licence and retain required notices.

- Food Menu Scroll Carousel: https://21st.dev/@kedhareswer/components/dish-orbit-carousel
  GSAP ScrollTrigger orbit transition, title wipe and colour band. Adapt to upright saree models and product state. Not food images or chef ratings. Use bounded transitions in the page; do not trap endless page scroll.
- Focus Blur Image Carousel: https://21st.dev/@kedhareswer/components/focus-pull-carousel
  Centred sharp image, smaller softer neighbours, swipe/drag/buttons; useful for bridal alternate.
- Scrollable Card Stack: https://21st.dev/@educalvolpz/components/scrollable-card-stack
  Stacked cards with scale/blur and navigation; useful for weave stack alternate.
- Hover Expand: https://21st.dev/@educalvolpz/components/hover-expand
  Expanding panels; useful for moods alternate.
- Aperture Reveal Carousel (optional, not added to required layout): https://21st.dev/@kedhareswer/components/aperture-carousel
