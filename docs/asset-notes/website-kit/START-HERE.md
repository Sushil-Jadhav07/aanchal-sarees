# NOOLAM — asset and Claude Code handoff kit

## What is inside
- All 15 requested section mockups: earlier nine + classic six, in separate reference folders.
- Two full-page context mockups.
- 22 newly generated reusable production images: 7 transparent model PNGs, 3 showroom slider photos, 2 background textures, 5 fabric macros, 2 craft photos, and 3 decorative PNGs (ribbon, paisley, rail).
- Colour/font/layout/motion tokens, frontend product data, asset manifest, section placement guide, component links and one consolidated Claude Code prompt.
- Open PREVIEW.html in your browser to inspect all references and assets. It is an index, not the finished store.

## Use with Claude Code
1. Extract this whole ZIP into a folder accessible to Claude Code.
2. Open your intended project folder with Claude Code. Tell it the extracted kit's absolute path.
3. Paste the complete contents of CLAUDE-CODE-PROMPT.md, or ask: 'Read this kit’s CLAUDE-CODE-PROMPT.md and implement it fully in this project.'
4. Claude should inspect the reference PNGs and map public/assets to live components. Follow docs/INSTALL.md only for a new project.
5. Run the built project, review desktop/mobile and the earlier/classic variant URLs.

## Important accuracy notes
This is NOT original layered source artwork and NOT a completed React website. All references are flattened generated mockups. Production assets are separate close matching recreations, not exact recovered photographs. The models have real alpha channels, with soft semi-transparent glow/edge regions; check them over the final background. All seven are full-body standing models; reference seated/bridal portraits are approximated by intentional CSS crops and compositions. Fabric macros do not exactly reproduce every garment. Magenta shares purple macro and orange shares mustard macro in demo data. No separate ivory fabric/model supplied. The rail is one flattened transparent asset, so cloth pieces cannot independently animate.

There are no original brand font files, real customer videos, certified product records, verified prices, backend code, checkout service or original individual miniature icon/arch assets. UI controls, typography, arch clipping, gold outlines and dots must be rebuilt in code. They are not missing raster images. No decorative SVG asset files are included. Component source is not vendored; verified links and adaptation instructions are in docs/COMPONENT-SOURCES.md.

The hero is an IMAGE SLIDER. Missing craft/stories videos also use image galleries until real media is supplied. Mockup video play marks are not instructions to fabricate videos. Cart/wishlist are local demo state, not live checkout.

Default combined homepage includes the six classic sections and unique earlier components; alternatives remain separate via config to avoid duplicate similar sections. See data/sections.json. All imagery is illustrative; replace with verified real catalogue/customer/supplier media before publishing commercial claims.
